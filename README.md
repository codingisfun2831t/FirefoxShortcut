# Firefox Shortcut



A command line tool for converting the Firefox.exe that replaced the old Firefox shortcut in newer versions, for those who either want the shortcut icon back or have file extensions on.

# How it works

It works by first ensuring the paths, and then moving the Firefox.exe launcher over to the Firefox Program Files folder as "launcher.exe". Then, using COM, it creates a shortcut to that to the same directory as the launcher.
